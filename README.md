# Constraints & Guardrails

约束与护栏系统定义 Agent 的边界，确保安全、可控的执行。

## 约束层级

```
┌─────────────────────────────────────┐
│  Level 4: Hard Constraints (硬约束)  │
│  - 不可覆盖，强制执行                 │
├─────────────────────────────────────┤
│  Level 3: Soft Constraints (软约束)  │
│  - 可覆盖，需记录理由                 │
├─────────────────────────────────────┤
│  Level 2: Guidelines (指导原则)      │
│  - 建议遵循，灵活处理                 │
├─────────────────────────────────────┤
│  Level 1: Preferences (偏好设置)     │
│  - 默认行为，可自由调整               │
└─────────────────────────────────────┘
```

## 配置文件

- `hard-constraints.yaml` - 硬约束（安全、权限）
- `soft-constraints.yaml` - 软约束（代码风格、架构）
- `tools-policy.yaml` - 工具使用策略
